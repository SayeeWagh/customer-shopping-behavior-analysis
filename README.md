# Customer Shopping Behavior Analysis

A data analytics project developed as part of my learning in Python, SQL, and Power BI. The project analyzes customer shopping data to understand purchasing patterns, customer preferences, discount usage, subscriptions, and spending behavior.

## Project Overview

The objective of this project is to explore customer shopping data, perform data analysis, and identify useful insights that can help understand customer behavior.

The project covers the following areas:

- **Data Analysis using Python:** Explore, clean, and prepare the dataset using Pandas and NumPy.
- **Database Management using MySQL:** Store and manage the processed data in a MySQL database.
- **SQL Analysis:** Write queries to answer business-related questions about customer purchases, revenue, discounts, and subscriptions.
- **Data Visualization using Power BI:** Create an interactive dashboard to visualize shopping trends and key metrics.

## Analysis Performed

The project explores several aspects of customer shopping behavior, including:

1. Revenue generated by different customer groups.
2. Discount usage and customer spending patterns.
3. Product ratings and customer preferences.
4. Purchase amounts based on shipping methods.
5. Spending patterns of subscribers and non-subscribers.
6. Discount rates across products.
7. Customer segmentation based on previous purchases.
8. Top-performing products within each category.
9. Repeat purchases based on subscription status.
10. Revenue contribution across different age groups.

## Getting Started

### Prerequisites

Install the following tools before running the project:

- Python 3.11
- MySQL Server and MySQL Workbench
- Visual Studio Code with Python and Jupyter extensions
- Power BI Desktop

### 1. Clone the Repository

```bash
git clone https://github.com/SayeeWagh/customer-shopping-behavior-analysis.git
cd customer-shopping-behavior-analysis
```

### 2. Set Up the Python Environment

Create and activate a virtual environment.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the required libraries:

```bash
python -m pip install --upgrade pip
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter ipykernel
```

### 3. Set Up the MySQL Database

1. Start MySQL Server and open MySQL Workbench.
2. Create the database:

```sql
CREATE DATABASE customer_behavior;
```

3. Open `Customer_Shopping_Behavior_Analysis.ipynb` in VS Code.
4. Select the Python interpreter from the `.venv` environment.
5. Run the notebook cells in order to prepare the data and load it into MySQL.

Update the database connection details according to your local MySQL configuration. Enter your password when prompted, and avoid storing credentials directly in the notebook.

**Note:** The notebook uses `if_exists="replace"` when loading the customer table, which replaces the existing table each time that cell runs.

### 4. Run the SQL Queries

Open `customer_behavior_sql_queries.sql` in MySQL Workbench, select the `customer_behavior` database, and execute the queries to explore the analysis questions listed above.

### 5. Open the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` in Power BI Desktop to explore the visualizations, key metrics, and interactive filters.

The report may require data source configuration depending on your local setup.
