# Customer Shopping Behavior Analysis — Python, MySQL & Power BI

An end-to-end customer behavior analytics project using Python, MySQL, and Power BI. This project explores customer shopping patterns, purchasing behavior, discounts, subscriptions, product ratings, and revenue trends to derive useful business insights.

**MySQL Adaptation:** This version adapts the original project's database workflow to MySQL while preserving the core analysis and business questions.

## 📌 Project Overview

The project demonstrates an end-to-end data analytics workflow, from data preparation to business analysis and visualization.

- **Data Preparation & EDA (Python):** Import, explore, clean, and transform customer shopping data using Pandas.
- **Database Integration (MySQL):** Load the cleaned dataset into a MySQL database using SQLAlchemy and PyMySQL.
- **Business Analysis (SQL):** Analyze customer segments, purchasing behavior, discounts, shipping preferences, subscriptions, and revenue.
- **Visualization (Power BI):** Use an interactive dashboard to explore customer trends and purchasing patterns.
- **Reporting:** Present findings through a project report and presentation.

## 🚀 Getting Started

### 1. Prerequisites

Install the following software:

- Python 3.11
- MySQL Server and MySQL Workbench
- Visual Studio Code with the Python and Jupyter extensions
- Power BI Desktop (for opening the dashboard)

### 2. Clone the Repository

Clone your GitHub repository and navigate to its directory:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_REPOSITORY_FOLDER
```

Replace the placeholders with your repository URL and folder name.

### 3. Create a Python Virtual Environment

Open the project folder in VS Code and run these commands in the terminal:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter ipykernel
```

### 4. Set Up MySQL

1. Start your local MySQL server.
2. Open MySQL Workbench and connect to your server.
3. Create the project database:

```sql
CREATE DATABASE customer_behavior;
```

4. Open `Customer_Shopping_Behavior_Analysis.ipynb` in VS Code.
5. Select the Python interpreter from the project's `.venv` environment.
6. Run the notebook cells in order.

The notebook prepares the dataset, connects to MySQL, and loads the cleaned data into the `customer` table.

**Database configuration:** Update the connection username if needed. Enter your MySQL password when prompted. Never commit database passwords or other credentials to GitHub.

> Note: The notebook uses `if_exists="replace"` when loading the table. This drops and recreates the existing `customer` table each time that cell is executed.

### 5. Run the SQL Analysis

Open `customer_behavior_sql_queries.sql` in MySQL Workbench.

Select the `customer_behavior` schema and execute the queries to explore the project's business questions, including:

1. Revenue generated by gender.
2. Customers who used discounts but spent at least the average purchase amount.
3. Products with the highest average review ratings.
4. Average purchase amounts by shipping type.
5. Spending and revenue comparisons between subscribers and non-subscribers.
6. Products with the highest discount rates.
7. Customer segmentation by previous purchases.
8. Top three products within each category.
9. Repeat buyers grouped by subscription status.
10. Revenue contribution by age group.

### 6. Explore the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` using Power BI Desktop.

If the dashboard's data source still points to a different database, update the connection to use the MySQL database and verify that the required tables and columns are available.

### 7. Review the Reports and Presentation

Refer to the included PDF report and PowerPoint presentation for the project's business context, analysis, and presentation of insights.
